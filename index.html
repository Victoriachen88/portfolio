跨市场量化回测系统

Python github.com/caiyuchen980-hash/cross-market-trading-backtester

本项目基于 Python 构建了一套跨市场量化回测工具，面向缺乏专业分析工具的零售投资者，帮助其以低成本、透明化的方式测试和比较不同交易策略的有效性。系统通过 yfinance 库实时获取美股、港股、A 股三大市场各 50 只代表性股票的三年期日频数据，采用滚动回测（Walk-Forward）方法消除前视偏差，以 Pandas 处理数据、Matplotlib 进行可视化，集成了 MACD、RSI、均线通道、均线振荡器及买入持有五种策略。实证结果显示，买入持有策略在美股市场表现最优（平均收益 147%），而 RSI、MACD 等主动策略在波动较大的港股与 A 股市场中更具优势。项目同时整合期权情绪分析（Max Pain、PCR、IV），为用户提供多维度决策参考。
